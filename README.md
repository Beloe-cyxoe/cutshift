# cut/shift

Браузерный инструмент для блочных коллажей и глитч-эффектов из фото: режет снимок на блоки, сдвигает и дублирует фрагменты, может выбивать блоки и смешивать два фото.

**Открыть:** https://beloe-cyxoe.github.io/cutshift/

Всё работает локально в браузере — фото никуда не загружается.

## Управление

- **R** — всё случайно
- **⌘Z / ⇧⌘Z** — отменить / вернуть
- **Пробел** (удерживать) — показать оригинал
- **F** — масштаб 1:1
- **⌘S** — скачать
- Двойной клик по слайдеру — сброс к значению по умолчанию
- Фото можно перетащить на холст или вставить из буфера

## Деплой

Статичный сайт из одного файла `index.html`. GitHub Pages: Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
